# Madhav Ecommerce Sales Dashboard

# Project Overview
This project is an Ecommerce Sales Dashboard created using Power BI.
The dashboard helps analyze sales, profit, quantity, customers, categories, and product performance.

# Project Objective
The main objective of this project is to analyze ecommerce data and identify useful business insights using interactive Power BI visualizations.

# Tools & Technologies
* Power BI
* Power Query
* DAX
* Excel

# Key KPIs
* Total Sales
* Total Profit
* Total Quantity
* Average Order Value
* Total Orders

# Dashboard Features
* Sales and profit analysis
* Monthly sales trend
* Category-wise analysis
* Product-wise analysis
* State-wise sales analysis
* Customer analysis
* Interactive slicers and filters
* KPI cards and charts

# Key Insights
* Identified top-performing products and categories.
* Analyzed monthly sales and profit trends.
* Compared sales performance across different states.
* Identified products and categories contributing to higher profit.
* Analyzed customer and order performance.
